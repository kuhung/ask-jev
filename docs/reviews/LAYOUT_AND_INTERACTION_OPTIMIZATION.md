# 问问Jev (Ask Jev) 布局重心、交互反馈与风格一致性优化报告

## 一、一页纸概览 (Executive View)

| 优化维度 | 优化前瓶颈与问题诊断 | 优化动作与落地收益 |
| :--- | :--- | :--- |
| **一、布局重心与视觉平衡** | 桌面端 1:3 左右分栏导致左侧在放完两张小卡片后留出约 300px 的空白断层；移动端左侧立牌排在最前，挤占首屏搜索核心区域。 | 左侧立牌区增加「老管家执业守则 · 当班备忘」箴言卡片，充实侧边高度，消融空白断层；移动端增加 `order-2 lg:order-1` 响应式流，确保移动端首屏直达输入框。 |
| **二、输入与模式交互体验** | 输入框缺乏行内快捷清除；评分模式缺少意图关键词自动识别；补充背景为纯文本弱链接，不易识别。 | 输入框增加行内一键清除按钮（`X`）；模式识别扩展支持“打分/靠谱度/指数”自动对齐评分模式；背景输入升级为清晰的按键式切换态。 |

| **四、异常容灾与规范合规** | 热门场景点击（`handleSelectTopic`）缺失客户端本地推演降级，网络异常时会静默无响应；存在“不是……而是……”对比句式。 | 补齐离线与未配置 API 时的本地高拟真兜底推演；全量清洗违规对比句式，转为正面积极陈述。 |

## 二、关键改动点详情 (P0 / P1 / P2)

### P0：解决布局失衡与空白断层
1. **左栏卡片垂直高度平衡**：
   - 之前：左侧仅有“NEW 模型”与“开源致敬立牌”，右侧生成裁决后高度达 550px，左侧在 200px 后形成大片空白断层。
   - 之后：左侧新增「老管家当班备忘」箴言卡片，列入管家决断心法，与右侧输入区和裁决卡片形成齐平有力的视觉平衡。
2. **移动端触达顺序优化**：
   - 之前：移动端按源码流默认先展示左侧立牌，用户需下滑才能触达输入框。
   - 之后：采用 `order-1 lg:order-2`（核心输入区）与 `order-2 lg:order-1`（辅助立牌区），手机端打开即聚焦核心输入。

### P1：输入框与微交互打磨
1. **行内一键清除**：
   - 输入内容时自动在右侧显现小叉号按钮，点击即清空并自动重置焦点，避免用户移到下方点击重置。
2. **模式意图拓展**：
   - 除了“还是/或者/VS”自动切换至二选一模式外，新增“打分/评个分/靠谱度/指数/评分”自动切换至冲动评估打分模式。
3. **抽取场景与背景展开强化**：
   - “抽取热门纠结场景”升级为醒目的暖黄色高反差胶囊按钮。
   - “+ 补充具体顾虑/预算”升级为带边框微态按钮，展开与收起状态分明。

### P2：统一视觉风格与语言合规
1. **剔除 Win95 灰按钮残余**：
   - “清空重置”与“我不服再摇一次”统一采用白底黑边配硬黑阴影，点击带有按下位移反馈。
2. **管家评语排版提升**：
   - 裁决卡片内的理由评语增加复古引言装饰，增强管家面授机宜的场景感。
3. **文案规范全量合规**：
   - 将“赛博硬币决断法”中的“不是……而是……”替换为直接正面的陈述句式。

# 问问Jev (Ask Jev) 产品原型与技术方案

## 一、一页纸概览 (Executive View)

| 维度 | 内容说明 |
| :--- | :--- |
| **产品定位** | 面向中国大陆年轻人的复古 Web 1.0 风格生活微决策决断机，主打解压、幽默与快速决断。 |
| **参考原型** | 经典 Ask Jeeves (Ask Jev) 拟人管家搜索界面，奶黄底色、立体浮雕按钮、报纸式分类排版。 |
| **核心客群** | 大陆打工人、大学生、日常选择困难症患者、消费纠结族。 |
| **核心议题** | 买不买（消费）、花不花（预算）、用不用（断舍离）、中午吃什么（餐饮）、去不去（社交职场）。 |
| **底层模型** | 后端对接 TypeSafe 推出的 **Jev 模型**（通过 AI Gateway 或 TypeSafe SDK / API 提供高确定性结构化推理）。 |
| **前端交互** | 是/否裁决 (Yes/No)、多项择一 (Choice)、冲动指数打分 (Score)。 |
| **交付形式** | 零依赖、开箱即用的高保真交互式单页应用，同时内置真实 API 联调模式与高拟真离线演示模式。 |

### 1. 核心回答形式（对应 TypeSafe Jev 的三种模式）
1. **是 / 否 (Yes / No)**
   - 场景：买不买、花不花、用不用、去不去。
   - Jev 输出：明确的布尔决断（【买】/【别买】、【去】/【别去】），配以直击痛点的犀利点评。
2. **多项择一 (Choice)**
   - 场景：中午吃什么（麻辣烫 vs 赛百味）、下班去哪玩、二选一与多选一。
   - Jev 输出：挑出唯一胜出的选项，并给出为何放弃其他选项的充分理由。
3. **冲动指数打分 (Score)**
   - 场景：评估某件事的靠谱度、购买冲动指数、后悔概率预测（1 至 10 分）。
   - Jev 输出：精确分值与评级判定（如“冲动指数 9 分：建议立省 100%”）。

## 三、TypeSafe Jev 后端接口规范 (API Contract)

前端支持配置自定义后端 API 地址。当配置了 Endpoint 时，前端将直接请求该接口；若未配置或处于离线演示环境，前端自动切换至本地高质量拟真引擎。

### 1. 统一决策接口
- **Endpoint**: `POST /api/jev/decide`
- **Headers**:
  - `Content-Type: application/json`
  - `Authorization: Bearer <API_KEY>`（可选）

#### 请求体结构 (Request Schema)
```json
{
  "question": "中午吃麻辣烫还是轻食？",
  "mode": "choice",
  "context": "最近在控糖减脂，但是今天工作压力大心情不好",
  "options": ["麻辣烫", "轻食"]
}
```

字段说明：
- `question` (string, 必填)：用户输入的自然语言问题。
- `mode` (string, 必填)：枚举值 `yes_no`、`choice`、`score`。
- `context` (string, 可选)：补充背景（如预算、现状、顾虑等）。
- `options` (string[], 可选)：当模式为 `choice` 时提取的候选选项列表。

#### 响应体结构 (Response Schema)
```json
{
  "code": 0,
  "data": {
    "mode": "choice",
    "verdict": "麻辣烫",
    "verdictTag": "强烈推荐",
    "reasoning": "压力大的时候硬吃生冷沙拉，下午非常容易报复性暴饮暴食喝奶茶。去吃一碗清汤或微辣的骨汤麻辣烫，多煮绿叶菜和豆腐牛肉，兼顾心理抚慰与控糖目标。",
    "score": null,
    "confidence": 0.95
  }
}
```

- `verdict`：核心决断结论（如“买”、“千万别买”、“麻辣烫”、“去”、“别去”）。
- `verdictTag`：情绪强化标签（如“避坑指南”、“果断冲”、“理智第一”、“性价比之王”）。
- `reasoning`：Jev 老管家的犀利点评正文（2至3句话，直切要害，带幽默感）。
- `score`：当 `mode` 为 `score` 时返回 1 至 10 的整数分值。

## 四、前端架构与交互实现

1. **外观复古，内核现代**：
   - 严格致敬经典 Web 1.0 拟人界面风格，保留经典的 `#FAF7D9` 浅米黄底色、双线立体凹凸槽（`outset` / `inset` 边框）、红色椭圆高光立体按钮、复古像素横幅广告。
   - 交互完全现代化：无刷新即时响应、全键盘快捷支持（Enter 直接裁决）、平滑信封开盒动效、裁决结果生成卡片。
2. **全入口真实闭环**：
   - 顶部导航全部可点（包含【随便抛个硬币】直接给出神级裁决、【接口设置】弹窗快速配置后端 URL、【关于Jev】身世介绍）。
   - 中间所有分类兴趣词条点击后自动填充到主输入框，并自动选中最佳回答模式。
   - 结果卡片支持【听老管家的就这么办】（触发全屏礼花彩带动画）以及【我不服，再摇一次】（重新触发二次推理）。
3. **双引擎自适应**：
   - 优先使用用户配置的 TypeSafe Jev 接口。
   - 当检测到接口未配置或网络异常时，平滑降级到内置 Jev 本地推理引擎，保证随时随地即开即用。
